# Project Rules & Guidelines

### PHP Application Redesign Safeguards
- **Preserve PHP Infrastructure**: When performing UI redesigns or frontend overhauls on `.php` pages (e.g., `index.php` or dashboard views), ensure the file remains a valid `.php` file with all PHP tags (`<?php ... ?>`), session handling, and backend logic intact.
- **Maintain Backend Route Integrity**: Do not alter or break existing backend route links, authentication paths (e.g., `auth/login.php`), or database handler scripts during visual redesigns.
